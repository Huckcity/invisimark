PNG, JPG, WebP, MP4, MOV, MKV or WebM. Use the version closest to the original: sharing sites often remove metadata.

What the result means

Watermark. The public Invisimark watermark says a tool marked the file as AI-generated or AI-manipulated. It doesn't say who marked it. Anyone can copy it onto another file or remove it.

Signed metadata. A C2PA manifest can name who signed the file and whether it was declared AI-made. A valid signature shows the manifest is unchanged. The name is only verified if the certificate chains to a trust list this service has loaded.
