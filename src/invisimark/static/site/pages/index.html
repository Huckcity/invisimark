How it works

  1. 1

    Upload and list recipients

    Choose the photo or video and type who is getting a copy: usernames, order numbers, anything you will recognise later.

  2. 2

    Send each person their own

    Download one folder per recipient and a case file. Every copy looks identical, but each carries a different pattern. Send people only their own copy, and keep the case file private.

  3. 3

    Trace a leak

    When a copy appears somewhere it should not, upload it with your case file. Invisimark reads the pattern and says whose copy it was, or tells you honestly that it cannot.
